# Number Guessing Game

A simple command-line game written in Python. The computer chooses a random
whole number from 1 to 100, and you try to guess it.

## Requirements

- Python 3

## Run the game

Open a terminal in this project folder and run:

```bash
python number_guessing_game.py
```

## How to play

Enter a whole-number guess when prompted. The game tells you whether your guess
is too high or too low. Keep guessing until you find the number; the game then
prints how many valid guesses you made. If you enter something that is not a
whole number, the game asks you to try again without counting it as an attempt.
